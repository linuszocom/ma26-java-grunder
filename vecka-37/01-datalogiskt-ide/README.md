## 🗣️ Målsvar att kunna utantill inför examinationen

När Pass 1 är klart ska du kunna återge dessa med egna ord:

> **Datalogiskt tänkande:** "Ett program handlar om data (vad vi har), handlingar (vad vi gör med det) och ordning (i vilken följd stegen måste ske). Fel ordning ger fel resultat — som att frimärka paketet efter att det redan skickats."

> **JDK vs IDE:** "JDK är verktyget som kompilerar och kör Java på datorn. IDE:n är arbetsbänken där jag skriver kod, trycker Run och läser felmeddelanden. De är inte samma sak — och inget av dem är en webbläsare eller Android-app."

> **Konsolen:** "Konsolen är textfönstret där programmet skriver ut resultat. Det är där jag ser att koden kördes — inte i själva kodfilen."
