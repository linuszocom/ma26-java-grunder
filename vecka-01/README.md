## 🎯 Veckans checklista (klar inför vecka 2?)

När veckan är slut ska du ha bockat av:

- [ ] Jag kan dela ett mini-problem i **data → handlingar → ordning** utan kod
- [ ] Jag har skapat ett Java-projekt i IDE:n och kört `main` i **konsolen**
- [ ] Jag kan förklara skillnaden **JDK** vs **IDE** med egna ord
- [ ] Jag kan deklarera och skriva ut `int`, `double`, `String` och `boolean`
- [ ] Jag kan skriva `if` / `else` / `else if` med jämförelser och `&&` / `||` / `!`
- [ ] Jag kan målsvaren för **datalogiskt tänkande**, **variabel** och **villkor** utantill
