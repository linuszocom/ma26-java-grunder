## 🎯 Veckans checklista (klar inför vecka 40?)

- [ ] Jag har ett **publikt** GitHub-repo och har gjort `add` → `commit` → `push`
- [ ] Jag ser minst en commit under **Commits** på GitHub
- [ ] Jag kan förklara skillnaden **klass** (mall) vs **objekt** (instans)
- [ ] Jag har skapat `Account.java` och minst ett objekt i `main`
- [ ] Jag kan anropa `deposit` och `withdraw` på ett objekt
- [ ] Jag kan förklara vad som händer när uttaget är **för stort** (saldo oförändrat + meddelande)
- [ ] Jag kan målsvaren för **Git**, **klass/objekt** och **uttagsregeln** utantill
